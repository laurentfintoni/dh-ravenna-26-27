## GenAI Disclosure

- slide scaffolding, based on outlines.
- marp management, incl. css boilerplate and tweaks (slides are created with Marp, every lesson folder includes the md original).

None of the slides or course materials are entirely generated by GenAI and given as is. Where some material (primarily copy) is generated (e.g. via scaffolding slides or creating practice templates) it is reviewed and edited/rewritten by me.
